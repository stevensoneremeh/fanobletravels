---
name: Legacy content fidelity
description: Why the legacy HTML must remain a content source for the modern site.
---

Do not assume the imported React pages contain all of the older HTML content. The React homepage and several inner pages originally omitted substantial original copy and galleries.

**Why:** A preservation audit found longer introductions and additional sections in the legacy pages that were absent from the corresponding React pages. Preserving only React content would silently lose material the user specifically wanted retained.

**How to apply:** Compare both content sources when redesigning or consolidating pages. Render preserved content in the main page, not inside whole-site iframes with duplicate navigation and footers.
